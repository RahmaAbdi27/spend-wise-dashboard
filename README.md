# SpendWise – Personal Budgeting Dashboard

## Project Description
SpendWise is an interactive personal budgeting website designed to help users manage their monthly budgets, track expenses, monitor savings, and calculate their remaining balances.

The application provides a simple dashboard where users can record expenses, update their budgets, and monitor their spending habits.

## Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality
- Git – Version control
- GitHub – Source code hosting
- Netlify – Website hosting and deployment
- Visual Studio Code – Code editor

## Deployment Process Summary
The SpendWise project was deployed using GitHub and Netlify.

The deployment process involved:

1. Reviewing and organizing the project files.
2. Uploading the complete project to a public GitHub repository.
3. Creating a Netlify account and connecting it to GitHub.
4. Importing the SpendWise GitHub repository into Netlify.
5. Configuring the deployment settings.
6. Deploying the website and generating a live Netlify URL.
7. Connecting the repository to Netlify for continuous deployment.

## Challenges Encountered During Deployment
- Understanding how to connect a GitHub repository to Netlify.
- Configuring the correct project directory for publishing.
- Ensuring that HTML, CSS, and JavaScript files load correctly on the live website.
- Understanding how automatic deployments work when changes are pushed to GitHub.

## Lessons Learned

1. How to host a website using Netlify.

3. How to connect GitHub repositories to Netlify.
